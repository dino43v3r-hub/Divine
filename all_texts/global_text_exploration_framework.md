# Global Text Exploration Framework

Source lane: all texts

The app can explore sacred scripture, wisdom literature, epic, myth, poetry,
law code, philosophy, ritual, chronicle, oral tradition, folklore, commentary,
and interpretation from every language family that can be responsibly sourced.

Coverage map:

- Afro-Asiatic: Hebrew, Aramaic, Arabic, Amharic, Coptic, Akkadian.
- Indo-European: Greek, Latin, Sanskrit, Persian, English, Spanish, French,
  German, Russian, Hindi.
- Sino-Tibetan: Classical Chinese, Mandarin, Tibetan, Burmese.
- Niger-Congo: Swahili, Yoruba, Igbo, Zulu, Xhosa, Akan.
- Austronesian: Malay, Indonesian, Tagalog, Hawaiian, Maori.
- Dravidian: Tamil, Telugu, Kannada, Malayalam.
- Turkic: Turkish, Azerbaijani, Uzbek, Kazakh, Uyghur.
- Uralic: Finnish, Hungarian, Estonian, Sami.
- Austroasiatic: Vietnamese, Khmer, Mon.
- Kra-Dai: Thai, Lao, Zhuang.
- Japonic: Japanese, Ryukyuan.
- Koreanic: Korean.
- Mongolic: Mongolian.
- Indigenous Americas: Nahuatl, Maya, Quechua, Aymara, Navajo, Cherokee, Cree,
  Ojibwe, Mapuche.
- Australian: Aboriginal language traditions such as Yolngu and Warlpiri.
- Papuan: Papuan language traditions, Tok Pisin, Hiri Motu.

Pattern observation:

Across global texts, possible divine-pattern signals should be tested through
creation story, moral order, wisdom, lament, exile, sacrifice, justice, mercy,
ritual, community, suffering, transformation, hope, and counterargument.

Guardrail:

Do not treat a pattern as universal just because it appears in a translated
sample. Track language family, source tradition, genre, translator choices,
historical context, colonial context, and rival interpretations.

Cross-layer question:

Does a proposed pattern appear across language families and text traditions while
still respecting each tradition's own meaning, context, and limits?

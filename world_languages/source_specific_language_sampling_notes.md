# Source-Specific Language Sampling Notes

Source lane: world languages
Source status: source-sampling expansion

The project should not call a pattern universal until actual language examples
are reviewed. This file defines a source-sampling path.

## Sampling Method

For each language or tradition, record:

- original word or phrase
- script and transliteration when relevant
- literal range
- common translation
- genre and speaker
- historical and community context
- colonial or missionary translation pressure
- rival interpretation
- whether the example supports, complicates, or contradicts the pattern

## Priority Samples

- Hebrew: ruach, hesed, shalom, tsedeq, dabar, hokmah.
- Greek: logos, pneuma, agape, dikaiosyne, metanoia, koinonia.
- Arabic: ruh, rahma, din, salam, hikma, adl.
- Sanskrit: dharma, atman, moksha, karma, bhakti, shanti.
- Pali: dukkha, metta, karuna, anicca, sangha.
- Chinese: dao, de, ren, li, tian, xin.
- Yoruba: ase, ori, iwa, alafia, community and ancestor terms.
- Quechua or Aymara: land, reciprocity, community, and memory terms.

## Universality Guardrail

If a translated word looks like order, spirit, wisdom, justice, peace, or
transformation, treat it as a question, not a conclusion. Similar English
glosses may hide different metaphysics, practices, and communities.

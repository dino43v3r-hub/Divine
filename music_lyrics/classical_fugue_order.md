Title: Fugue Of Returning Voices
Genre: Classical / Baroque
Type: Original analysis seed

Subject:
A single voice enters with a precise melodic idea.

Answer:
A second voice repeats the subject from another height.

Development:
More voices enter, each carrying the same theme in a different place.
The pattern becomes complex but remains intelligible.
Order is not silence; order is many voices held together.

Resolution:
The voices return to the home key.
The final cadence sounds like argument becoming communion.

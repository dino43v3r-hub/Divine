# Hypothesis Review Rules

These rules keep the divine-pattern project careful.

## Evidence Labels

Use these labels when reviewing a pattern:

- Source-backed finding: directly supported by cited sources or analyzed text.
- Plausible hypothesis: reasonable connection, but not proven by the current data.
- Speculative claim: interesting idea with weak or indirect support.
- Unsupported claim: should not be stated as true until better evidence is found.

## Review Questions

For every proposed pattern, ask:

1. Which source supports it?
2. Is the source theological, philosophical, scientific, historical, or personal?
3. Does the pattern appear across multiple sources or only one?
4. Could there be a simpler explanation?
5. Does the claim confuse correlation with proof?
6. What evidence would weaken or falsify the claim?
7. What would a fair critic say?

## Project Boundary

This project can analyze relationships between God-concepts, faith, ritual,
morality, community, neuroscience, and human behavior.

It should not claim that AI has proven divine reality.

The strongest version of the project is not "AI proves God." It is:

AI can help organize interdisciplinary evidence and identify research hypotheses
about how faith, God-concepts, and human behavior relate.

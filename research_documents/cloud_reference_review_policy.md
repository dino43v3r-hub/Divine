# Cloud Reference Review Policy

Type: Source review guardrail
Source status: reviewed cloud reference policy

This project may collect daily cloud references as candidate leads. A candidate
reference is not strong evidence until it has been reviewed.

Review checklist:

1. Open the original source, not only a search result.
2. Identify the author, publisher, date, source type, and qualifications.
3. Separate primary source, scholarly source, reference entry, journalism,
   opinion, sermon, devotional writing, and speculative material.
4. Check whether the source actually supports the claim being made.
5. Record counterarguments or rival interpretations.
6. Avoid copying copyrighted text into the repository; store metadata,
   summaries, and short notes only.
7. Mark reviewed items as reviewed cloud reference or source reviewed.

Evidence rule:

Unreviewed cloud references can suggest research questions, but they should not
increase confidence in a divine pattern. Strong evidence requires original
source review, source quality, context, and pressure testing.

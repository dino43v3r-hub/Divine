# Pattern Revision Rules

Type: hypothesis revision guardrail
Source status: operating rule

The project should revise or weaken the divine-pattern hypothesis wherever a
pressure test exposes failure. The goal is not to protect the pattern from
criticism; the goal is to make it truer, humbler, and more useful.

## Revision Triggers

- A suffering case remains unresolved and the current pattern implies closure.
- A source shows Christian language being used for coercion, abuse, racism,
  colonial control, or institutional self-protection.
- A cross-cultural or comparative source supports only broad human recurrence,
  not a specifically Trinitarian claim.
- A biblical-language note depends on a word outside its literary, canonical, or
  historical context.
- A science source supports only a narrow technical claim while the report uses
  it for metaphysical proof.
- A cloud-reference candidate has not been checked against original source,
  author context, publication context, and counterarguments.

## Weakening Labels

- `research_question_only`: useful for asking better questions, not evidence.
- `shared_human_pattern`: recurring motif without Christian-specific proof.
- `limited_christian_signal`: source supports a narrow Christian claim only.
- `weakened_by_pressure`: pattern language must be revised before reuse.
- `do_not_strengthen_claim`: source or case should not increase confidence.

## Revision Actions

- Narrow the claim.
- Add a counterargument.
- Move from "evidence" to "question."
- Separate broad human recurrence from Trinitarian evidence.
- Add a harmed-community or victim-centered reading.
- Require original-source review before promotion.
- Say explicitly that repair is absent when repair is absent.

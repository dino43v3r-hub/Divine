# Cloud Reference Promotion Decision Log

Type: evidence promotion log
Source status: review gate

This log records decisions about whether routed daily cloud references can move
from candidate leads toward stronger evidence. It is intentionally conservative.

## Promotion Rule

A cloud reference may strengthen a claim only when:

- the original source was checked beyond metadata,
- author and publication context were identified,
- the smallest supported claim was written,
- at least one counter-reading was named,
- relevant pressure tests were considered,
- the claim survives without overreach.

## Current Decision Categories

### Theologian Candidates

- Default decision: `candidate_lead_only`.
- Promotion need: primary text, era, doctrinal question, disagreement, and
  reception context.
- Reason: theology search results often point to useful works, but the pattern
  must not treat metadata as doctrine.

### Science / Quantum Candidates

- Default decision: `research_question_only`.
- Promotion need: qualified source, technical scope, allowed conclusion,
  counterargument, and math/statistics/logic filter check.
- Reason: science sources can discipline claims, but they do not prove God.

### Interreligious Testimony Candidates

- Default decision: `reviewed_limited_testimony` only after source and context
  checks.
- Promotion need: public ethical testimony, comparative-religion context,
  psychology/anthropology counter-reading, long-term fruit, and Trinitarian
  discernment.
- Reason: testimony can matter deeply without functioning as statistical proof.

### Gifts Of The Holy Ghost Candidates

- Default decision: `candidate_signal_only`.
- Promotion need: Christ-centered fruit, love, service, justice, community
  accountability, and protection from coercion.
- Reason: spectacular experiences must be tested more strictly, not less.

### Language / Text-Tradition Candidates

- Default decision: `mapped_not_universal`.
- Promotion need: source-specific text, language, translation choice, genre,
  tradition self-understanding, and counter-reading.
- Reason: a routed language or tradition label is not coverage.

## Current Global Decision

No unreviewed daily candidate should be marked `reviewed_strong_evidence`.
Strong labels require a human source note in the appropriate layer folder.

## Seven-Newest Candidate Review Rule

Before the next version changes confidence language, review the seven newest
candidate references one by one.

For each candidate record:

- original source checked beyond title, abstract, or search metadata,
- author expertise and institutional or tradition context,
- publication, venue, date, edition, translation, or transmission context,
- smallest claim the source actually supports,
- counterargument or rival interpretation,
- routed layer and leading pattern affected, if any,
- decision: `candidate_lead_only`, `mapped_not_universal`,
  `reviewed_limited_evidence`, `reviewed_limited_testimony`, or
  `reviewed_strong_evidence`.

Default decision remains conservative until the source has been converted into
a human-reviewed note in the relevant lane folder.
